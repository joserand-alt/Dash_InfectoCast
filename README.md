# Painel InfectoCast Academy 🩺🎙️

Dashboard inteligente de acompanhamento de alunos, engajamento e captação de leads da **InfectoCast Academy**.

---

## 🚀 Funcionalidades

- **Visão Geral & KPIs:** Total de alunos ativos, cursos, módulos, taxas de conclusão e engajamento.
- **Progresso Detalhado do Aluno:** Visualização por aula e módulo, histórico de acessos, status (Ativo, Concluído, Em Risco, Abandonou, Nunca Acessou).
- **Engajamento por Módulo:** Taxas de conclusão, pontos de desistência e distribuição de visualizações.
- **Retenção & Abandono:** Alertas de alunos em risco e sem acesso recente.
- **Linha Temporal & Leads RD/WhatsApp:** Cruzamento de dados de captação e conversão de leads.
- **Histórico Completo de Interações:** Modal individual de aluno com logs cronológicos de aulas assistidas.

## 💻 Como Atualizar Localmente

1. Execute `python gerador.py` para sincronizar os dados da API / planilhas e atualizar o `index.html`.
2. Dê um duplo clique em `PUBLICAR_NO_GITHUB.bat` para enviar as atualizações ao GitHub Pages.
